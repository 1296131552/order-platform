## 二、项目初始化

### 2.1 创建项目

```bash
# 使用 Vite 创建项目
npm create vite@latest order-platform-web -- --template vue-ts

cd order-platform-web
npm install
```

### 2.2 安装依赖

```bash

# 路由和状态管理
npm install vue-router@4 pinia

npm install echarts
```

## 四、核心文件配置

### 4.1 main.ts 入口文件

```typescript
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import ElementPlus from 'element-plus'
import 'element-plus/dist/index.css'
import * as ElementPlusIconsVue from '@element-plus/icons-vue'
import App from './App.vue'
import router from './router'

const app = createApp(App)

// 注册所有图标
for (const [key, component] of Object.entries(ElementPlusIconsVue)) {
  app.component(key, component)
}

app.use(createPinia())
app.use(router)
app.use(ElementPlus)
app.mount('#app')
```

### 4.2 router/index.ts 路由配置

```typescript
import { createRouter, createWebHistory } from 'vue-router'
import type { RouteRecordRaw } from 'vue-router'

const routes: RouteRecordRaw[] = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/login/index.vue')
  },
  {
    path: '/',
    name: 'Layout',
    component: () => import('@/views/layout/DefaultLayout.vue'),
    redirect: '/order',
    children: [
      {
        path: 'order',
        name: 'OrderList',
        component: () => import('@/views/order/List.vue')
      }
    ]
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
```

## 六、API 对接指南

### 6.1 定义接口类型

```typescript
// src/types/api.d.ts
export namespace Api {
  namespace Order {
    interface ListParams {
      current: number
      size: number
      orderNo?: string
      customerName?: string
      statusCode?: string
    }

    interface ListResponse {
      records: Order[]
      total: number
    }

    interface Order {
      id: number
      orderNo: string
      customerName: string
      statusCode: string
      totalAmount: number
      createdAt: string
    }
  }
}
```

### 6.2 封装API

```typescript
// src/api/order.ts
import request from './index'

export const orderApi = {
  list: (params: Api.Order.ListParams) => {
    return request.get<Api.Order.ListResponse>('/orders', { params })
  }
}
```

### 6.3 页面使用

```vue
<script setup lang="ts">
import { orderApi } from '@/api/order'

const fetchData = async () => {
  const res = await orderApi.list({
    current: 1,
    size: 10
  })
  tableData.value = res.data.records
}
</script>
```

## 八、常见问题解决

### Q1: 跨域问题

**解决方法**：在 vite.config.ts 中配置代理

```typescript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

### Q2: 样式不生效

**检查项**：
1. 是否导入了全局样式
2. scoped 是否限制了样式
3. 是否使用了正确的选择器

### Q3: 类型报错

**解决方法**：
1. 安装类型定义：`npm install -D @types/node`
2. 检查 tsconfig.json 配置
3. 重启IDE

### Q4: 图标不显示

**正确用法**：
```vue
<el-icon><Plus /></el-icon>
```

## 九、开发规范

### 9.1 命名规范
- 页面文件：PascalCase（如 `OrderList.vue`）
- 组件文件：PascalCase（如 `TablePage.vue`）
- 工具文件：camelCase（如 `format.ts`）
- 常量文件：UPPER_CASE（如 `API_URL.ts`）

### 9.2 代码风格
- 使用 `<script setup>` 语法
- 优先使用 Composition API
- 使用 TypeScript 类型
- 添加适当的注释

### 9.3 Git 提交规范
```bash
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
```
