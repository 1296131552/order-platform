## 一、设计理念

### 1.1 设计原则

**实用性优先**
- 快速开发：1月12日前完成基础功能，时间紧迫
- 易于维护：代码清晰，便于团队协作
- 稳定可靠：基于成熟技术栈，降低风险

**渐进式优化**
- 第一阶段：实现核心功能，不过度设计
- 第二阶段：优化用户体验，添加高级功能
- 第三阶段：性能优化，完善细节

**参考借鉴**
- 参考 Art Design Pro 的优秀设计思想
- 但不完全照搬，根据项目特点简化
- 保持代码简洁，避免过度抽象

### 1.2 设计目标

**功能目标**
- ✅ 完整的订单→发运→签收流程管理
- ✅ 直观的数据看板和地图可视化
- ✅ 高效的异常处理和附件管理
- ✅ 完善的用户权限控制

**性能目标**
- 首屏加载时间 ≤ 2秒
- API响应时间 ≤ 500ms
- 看板数据刷新 ≤ 3秒
- 支持并发 50+ 用户

**体验目标**
- 操作流程简洁直观
- 错误提示清晰友好
- 支持键盘快捷操作
- 响应式布局（暂不考虑移动端）

## 二、技术选型

### 2.1 前端框架

**选择：Vue 3.3.4**

**理由**：
- ✅ Composition API：逻辑复用性强
- ✅ `<script setup>` 语法简洁
- ✅ 性能优于 Vue 2
- ✅ 生态完善，社区活跃
- ✅ 团队有使用经验

**不使用 React**：
- 学习曲线较陡
- 开发效率不如 Vue 3
- 团队不熟悉

### 2.2 开发语言

**选择：TypeScript 5.x**

**理由**：
- ✅ 类型安全，减少运行时错误
- ✅ IDE 智能提示完善
- ✅ 大型项目维护性好
- ✅ Element Plus 有完整类型定义

### 2.3 构建工具

**选择：Vite 4.4.5**

**理由**：
- ✅ 开发服务器极速启动
- ✅ HMR 热更新速度快
- ✅ 生产构建优化好
- ✅ 官方推荐，Vue 3 默认工具

**不使用 Webpack**：
- 配置复杂
- 启动慢
- 开发体验差

### 2.4 UI组件库

**选择：Element Plus**

**理由**：
- ✅ Vue 3 生态最好的组件库
- ✅ 组件丰富，满足业务需求
- ✅ 文档完善，中文友好
- ✅ 团队有使用经验

**不使用 Ant Design Vue**：
- API 风格不如 Element Plus
- 学习成本稍高

### 2.5 状态管理

**选择：Pinia**

**理由**：
- ✅ Vue 3 官方推荐
- ✅ API 简洁，学习成本低
- ✅ TypeScript 支持完善
- ✅ 轻量级，满足项目需求

**不使用 Vuex**：
- Pinia 是 Vue 3 官方方案
- Vuex 4 对 Vue 3 支持不完善

### 2.6 其他依赖

| 依赖 | 版本 | 用途 | 理由 |
|------|------|------|------|
| Vue Router | 4.x | 路由管理 | 单页应用必备 |
| Axios | 1.6.x | HTTP 请求 | 成熟稳定 |
| ECharts | 5.x | 数据可视化 | 功能强大 |
| 高德地图 API | - | 地图可视化 | 业务需求 |
| Day.js | 1.11.x | 日期处理 | 轻量级 |
| VueUse | 10.x | 组合式API工具 | 提升效率 |
| SCSS | - | CSS 预处理器 | 团队熟悉 |

### 2.7 不使用的技术

❌ **Tailwind CSS**
- 团队不熟悉，学习成本高
- 时间紧迫，来不及学习
- SCSS 已经足够用

❌ **React**
- 团队不熟悉
- 开发效率不如 Vue 3

❌ **MobX**
- Pinia 是官方推荐
- 更适合 Vue 3

### 4.2 目录设计说明

#### 4.2.1 api/ - API接口层

**职责**：封装所有后端API接口

**设计原则**：
- 按业务模块划分文件
- 统一的错误处理
- 统一的请求/响应格式

**示例**：
```typescript
// order.ts
export const orderApi = {
  list: (params: Order.QueryParams) => request.get('/orders', { params }),
  detail: (id: number) => request.get(`/orders/${id}`),
  create: (data: Order.CreateDTO) => request.post('/orders', data)
}
```

#### 4.2.2 components/ - 公共组件层

**职责**：可复用的UI组件

**分类**：
- **业务组件**：与业务强相关的组件（MapRoute、Timeline等）
- **通用组件**：通用UI组件（TablePage、SearchForm等）

**组件粒度**：
- 只封装超过2次使用的功能
- 保持简单，避免过度封装
- 优先使用 Element Plus 原生组件

#### 4.2.3 composables/ - 组合式函数层

**职责**：可复用的逻辑逻辑

**优势**：
- 逻辑复用，避免代码重复
- 代码组织更清晰
- 便于测试和维护

**示例**：
- `useTable` - 表格数据管理
- `useUpload` - 文件上传
- `useAuth` - 权限验证

#### 4.2.4 views/ - 页面视图层

**职责**：具体的业务页面

**组织方式**：
- 按功能模块划分文件夹
- 每个模块包含相关的页面
- 复杂页面拆分组件

## 八、API对接方案

### 8.1 请求封装

**基础配置**：
```typescript
const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})
```

**请求拦截器**：
```typescript
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

**响应拦截器**：
```typescript
request.interceptors.response.use(
  response => response.data,
  error => {
    // 统一错误处理
    ElMessage.error(error.message)
    return Promise.reject(error)
  }
)
```

### 9.3 样式规范

- **使用 scoped**：避免样式污染
- **使用 BEM 命名**：块-元素-修饰符
- **避免深度选择器**：性能考虑
- **使用变量**：便于主题定制

## 十、开发规范

### 10.1 命名规范

**文件命名**：
- 页面组件：PascalCase（如 `OrderList.vue`）
- 业务组件：PascalCase（如 `MapRoute.vue`）
- 工具函数：camelCase（如 `formatDate.ts`）
- 常量文件：UPPER_CASE（如 `API_URL.ts`）

**变量命名**：
- 组件变量：camelCase（如 `tableData`）
- 常量：UPPER_SNAKE_CASE（如 `API_URL`）
- 私有变量：前缀下划线（如 `_internalData`）

### 10.2 代码风格

**使用 `<script setup>` 语法**：
```vue
<script setup lang="ts">
import { ref } from 'vue'

const loading = ref(false)
</script>
```

**使用 TypeScript 类型**：
```typescript
interface Order {
  id: number
  orderNo: string
}

const order = ref<Order>()
```

### 10.3 注释规范

**文件注释**：
```typescript
/**
 * 订单API
 * @module api/order
 */
```

**函数注释**：
```typescript
/**
 * 获取订单列表
 * @param params 查询参数
 * @returns 订单列表
 */
export function getOrderList(params: Order.QueryParams) {
  // ...
}
```

**代码注释**：
```typescript
// 检查权限
if (!hasAuth('order:view')) {
  return
}
```

## 十一、性能优化

### 11.1 代码分割

**路由懒加载**：
```typescript
const OrderList = () => import('@/views/order/List.vue')
```

**组件懒加载**：
```vue
<el-button v-lazy="isShow">按钮</el-button>
```

### 11.2 缓存策略

**接口缓存**：
- 相同请求5秒内只发一次
- 使用 Pinia 缓存接口数据

**本地缓存**：
- 使用 localStorage 存储用户信息
- 使用 sessionStorage 存储临时数据

### 11.3 列表优化

**虚拟滚动**：
- 大数据量列表（>1000条）使用虚拟滚动
- Element Plus Table 支持虚拟滚动

**分页加载**：
- 默认分页大小：10条/页
- 避免一次性加载大量数据

### 11.4 图片优化

- 使用 WebP 格式
- 图片懒加载
- CDN 加速
