# 订单可视化平台 - 前端示例项目

**一个完整可运行的后台管理系统示例，作为项目开发的参考和兜底**

---

## 🚀 快速开始

### 第一步：安装依赖

```bash
cd example
npm install
```

### 第二步：启动开发服务器

```bash
npm run dev
```

### 第三步：查看效果

浏览器自动打开 `http://localhost:3000`，你会看到登录页面。

**测试账号**：
- 用户名：admin
- 密码：123456

## 🚨 注意事项

### 项目定位

这是一个**示例和兜底项目**，用于：
1. 展示完整的前端架构和代码风格
2. 作为新功能开发的参考
3. 在主项目开发延迟时作为兜底方案

### 实际开发时需要调整

1. **对接真实 API**
   - 当前 API 调用为模拟数据
   - 需要根据实际后端 API 调整接口

2. **权限控制**
   - 实现真实的 JWT Token 机制
   - 完善路由守卫逻辑
   - 实现细粒度的权限控制

3. **数据持久化**
   - 实现真实的本地存储策略
   - 实现缓存策略

## 📞 问题反馈

如果遇到问题：
1. 检查 Node.js 版本（需要 >= 18.x）
2. 检查 npm 版本（建议 >= 9.x）
3. 删除 `node_modules` 文件夹后重新安装
4. 检查端口 3000 是否被占用
