## 功能说明

`LoggingAspect` 是一个基于 AOP 的日志切面，自动记录所有 Controller 层接口的：

- ✅ 请求 URL 和 HTTP 方法
- ✅ 请求类名和方法名
- ✅ 请求参数
- ✅ 客户端 IP 地址
- ✅ 响应内容
- ✅ 执行耗时
- ✅ 异常信息（如有）

**适用范围**：所有 `com.order.platform.*.controller` 包下的接口

---

## 切面配置

### 1. 切点定义

```java
@Pointcut("execution(* com.order.platform.*.controller..*.*(..))")
public void controllerPointcut() {
}
```

**说明**：
- `*` - 任意返回类型
- `com.order.platform.*.controller` - 任意模块的 controller 包
- `..*.*(..)` - 任意子包、任意类、任意方法、任意参数

### 2. 组件配置

```java
@Slf4j
@Aspect
@Component
public class LoggingAspect {
    // ...
}
```

**说明**：
- `@Component` - 被 Spring 扫描并注册为 Bean
- `@Aspect` - 标识为切面类
- `@Slf4j` - Lombok 日志注解

### 3. 扫描配置

启动类 `ApiApplication` 已配置：

```java
@ComponentScan(basePackages = "com.order.platform")
```

**说明**：会扫描 `com.order.platform` 下的所有组件，包括：
- `com.order.platform.common.aspect.LoggingAspect`
- `com.order.platform.user.controller.AuthController`
- 其他业务模块的 Controller

## 使用说明

### 1. 自动生效

**无需额外配置**，所有 Controller 层接口自动记录日志。

### 2. 日志级别配置

在 `application.yml` 中配置：

```yaml
logging:
  level:
    root: INFO
    com.order.platform: DEBUG
```

### 3. 新增接口

**新增 Controller 时**，只需确保：

1. 类在 `com.order.platform.*.controller` 包下
2. 类使用 `@RestController` 或 `@Controller` 注解

**示例**：

```java
package com.order.platform.order.controller;

@RestController
@RequestMapping("/api/order")
public class OrderController {

    @PostMapping("/create")
    public Result<Order> createOrder(@RequestBody OrderDTO dto) {
        // ... 业务逻辑
        // LoggingAspect 会自动记录此接口的请求和响应
    }
}
```

### 4. 跳过日志记录

如果某个接口不想记录日志（如健康检查），可以：

**方法1：移到其他包**

```java
// 不在 controller 包下，不会被切面拦截
package com.order.platform.api.health;

@RestController
public class HealthController {
    // ...
}
```

**方法2：自定义注解排除（需要扩展 LoggingAspect）**

## 日志格式化特性

### 1. Result 对象格式化

自动提取 `Result` 对象的关键字段：

```java
Result{code=200, message=操作成功, data=Page{total=100, records=[5 条记录]}}
```

### 2. 长内容截断

响应内容超过 1000 字符时自动截断：

```java
Result{data=Collection[150 个元素] (示例: Order{...}, ...)... (总长度: 2534)}
```

### 3. IP 地址获取

自动获取真实客户端 IP，支持代理：

```java
X-Forwarded-For -> X-Real-IP -> Proxy-Client-IP -> WL-Proxy-Client-IP -> RemoteAddr
```

## 性能考虑

### 1. 性能监控

自动记录执行耗时：
- ✅ < 3秒：普通日志（INFO）
- ⚠️ > 3秒：警告日志（WARN）

### 2. 反射优化

使用反射获取字段值，仅在必要时使用：
- 格式化 Result 对象
- 格式化 Page 对象
- 格式化 Collection 对象

## 注意事项

1. **切点表达式**：确保 Controller 在正确的包下
2. **日志级别**：生产环境建议使用 INFO，开发环境使用 DEBUG
3. **敏感信息**：日志中会记录请求参数，注意密码等敏感信息的处理
4. **性能影响**：AOP 切面有轻微性能开销，但可以忽略
