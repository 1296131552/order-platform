## 💡 最佳实践总结

### 1. 接口解耦

**问题**：模块间循环依赖

**解决**：定义接口在 common 模块，实现在业务模块

```java
// common 模块
public interface UserRoleProvider {
    List<String> getRoleCodesByUserId(Long userId);
}

// user 模块
@Service
public class UserRoleService implements UserRoleProvider {
    // 实现
}
```

---

### 2. 可选依赖处理

**问题**：依赖不存在时启动失败

**解决**：使用 `@Autowired(required = false)`

```java
public AuthInterceptor(JwtUtil jwtUtil,
                      @Autowired(required = false) UserRoleProvider userRoleProvider) {
    this.userRoleProvider = userRoleProvider;

    if (this.userRoleProvider == null) {
        log.warn("UserRoleProvider 未注入，使用降级方案");
    }
}
```

---

### 3. ThreadLocal 防护

**问题**：异常时 ThreadLocal 无法清理

**解决**：多层防护机制

```java
boolean userContextSet = false;

try {
    // 业务逻辑
    CurrentUserHolder.set(currentUser);
    userContextSet = true;
    return true;
} catch (Exception e) {
    // 异常清理
    if (userContextSet) {
        CurrentUserHolder.clear();
        userContextSet = false;
    }
    throw e;
} finally {
    // 兜底保障
    if (userContextSet) {
        log.error("ThreadLocal 未清理");
        CurrentUserHolder.clear();
    }
}
```

---

### 4. 异常细分处理

**问题**：捕获所有 Exception 统一处理

**解决**：细分异常类型

```java
try {
    // Token 解析
} catch (ExpiredJwtException e) {
    throw new BusinessException(ResponseCode.TOKEN_EXPIRED);
} catch (SignatureException | MalformedJwtException e) {
    throw new BusinessException(ResponseCode.TOKEN_INVALID);
} catch (Exception e) {
    throw new BusinessException(ResponseCode.TOKEN_INVALID);
}
```

### 5. 启动时健康检查

**问题**：配置问题在运行时才暴露

**解决**：启动时打印警告

```java
@PostConstruct
public void init() {
    if (userRoleProvider == null) {
        log.warn("┌─────────────────────────────────────────┐");
        log.warn("│ ⚠️  UserRoleProvider 未注入              │");
        log.warn("│ 影响：无法从数据库查询用户角色            │");
        log.warn("└─────────────────────────────────────────┘");
    }
}
```

### 6. 防御性编程

**原则**：不信任任何外部输入

```java
// 校验 userId
if (result.userId == null) {
    log.error("userId 为空，Token 可能被篡改");
    throw new BusinessException(ResponseCode.TOKEN_INVALID);
}

// 容错处理
if (result.username == null || result.username.isEmpty()) {
    log.debug("username 为空（允许）");
    // 不抛异常，允许继续
}
```

### 7. 日志分级

| 级别 | 使用场景 | 示例 |
|------|---------|------|
| ERROR | 严重问题，需要立即处理 | `userId 为空，Token 被篡改` |

### 8. MyBatis 注解形式

**适用场景**：
- ✅ 简单查询（单表、字段少）
- ✅ SQL 固定（无需动态拼接）

**不适用场景**：
- ❌ 复杂多表联查
- ❌ 需要动态 SQL

```java
@Mapper
public interface UserRoleMapper extends BaseMapper<UserRole> {

    @Select("SELECT role_code FROM t_user_role " +
            "WHERE user_id = #{userId} " +
            "AND is_enabled = 1 AND is_deleted = 0")
    List<String> selectRoleCodesByUserId(Long userId);
}
```

String token = authorization.substring(7).trim();

### 10. 空值处理

**原则**：返回空集合而非 null

```java
// ✅ 推荐
return List.of();  // 空列表

// ❌ 不推荐
return null;  // 可能导致空指针
```
