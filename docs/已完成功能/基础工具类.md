## 📋 功能概述

本阶段补充了 common 模块的三个基础工具类，支持用户登录和列表查询功能：

- **PageResult**：分页响应封装，统一列表查询返回格式

- **PasswordEncoder**：密码加密器，使用 BCrypt 算法保护用户密码

## 🏗️ 实现内容

### 1. PageResult（分页响应封装）

#### 文件位置

`common/response/PageResult.java`

#### 功能说明

统一分页查询的响应格式，支持：
- 从 MyBatis-Plus Page 对象快速构建
- 手动构建分页响应
- 空响应快捷方法

#### 代码结构

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class PageResult {
    private List records;    // 数据列表
    private long total;      // 总记录数
    private long current;    // 当前页码
    private long size;       // 每页大小
    private long pages;      // 总页数

    // 从 MyBatis-Plus Page 构建
    public static <T> PageResult of(Page page)

    // 手动构建
    public static <T> PageResult of(List records, long total, long current, long size)

    // 空响应
    public static <T> PageResult empty()
}
```

#### 使用示例

```java
@GetMapping("/list")
public Result list(
    @RequestParam(defaultValue = "1") long current,
    @RequestParam(defaultValue = "10") long size) {

    // 从 MyBatis-Plus 构建
    Page page = orderService.page(new Page<>(current, size));
    return Result.success(PageResult.of(page));
}

// 手动构建（不依赖 MyBatis-Plus）
List records = getUserList();
long total = getUserCount();
return Result.success(PageResult.of(records, total, 1, 10));

// 空响应
return Result.success(PageResult.empty());
```

#### 响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [...],
    "total": 100,
    "current": 1,
    "size": 10,
    "pages": 10
  }
}
```

### 2. StringUtil（字符串工具类）

#### 文件位置

`common/util/StringUtil.java`

#### 功能说明

提供字符串常用操作，基于 Hutool 的 StrUtil 进行封装：
- **判空**：isEmpty、isBlank
- **脱敏**：手机号、身份证、邮箱、银行卡号
- **截断**：truncate、substring
- **随机生成**：randomNumeric、randomString
- **其他**：trim、toCamelCase、toSnakeCase

#### 脱敏规则

| 类型 | 脱敏规则 | 示例 |
|------|----------|------|
| 手机号 | 保留前3后4 | 13812345678 → 138****5678 |
| 身份证 | 保留前6后4 | 330102199001011234 → 330102********1234 |
| 邮箱 | 保留首字母和域名 | abc@example.com → a***@example.com |
| 银行卡 | 只显示后4位 | 6222021234567890123 → ************0123 |

#### 使用示例

```java
// 判空
boolean empty = StringUtil.isEmpty(str);
boolean blank = StringUtil.isBlank(str);

// 脱敏
String phone = StringUtil.maskPhone("13812345678");          // 138****5678
String idCard = StringUtil.maskIdCard("330102199001011234"); // 330102********1234
String email = StringUtil.maskEmail("abc@example.com");      // a***@example.com
String cardNo = StringUtil.maskBankCard("6222021234567890123"); // ************0123

// 截断
String truncated = StringUtil.truncate(str, 20);  // 超长用...
String sub = StringUtil.substring(str, 10);       // 截取前10个字符

// 随机生成
String numeric = StringUtil.randomNumeric(6);     // 6位随机数字
String random = StringUtil.randomString(10);      // 10位随机字符串

// 其他
String trimmed = StringUtil.trim(str);            // 去除两端空白
String camel = StringUtil.toCamelCase("order_no"); // orderNo
String snake = StringUtil.toSnakeCase("orderNo"); // order_no
```

### 3. PasswordEncoder（密码加密器）

#### 文件位置

`common/config/SecurityConfig.java`

#### 功能说明

使用 Spring Security 的 BCryptPasswordEncoder 进行密码加密和验证。

#### BCrypt 算法特点

- 自动加盐，每次加密结果不同
- 单向加密，不可逆
- 安全性高，业界标准

#### 配置代码

```java
@Configuration
public class SecurityConfig {

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}
```

#### 使用示例

```java
@Service
@RequiredArgsConstructor
public class UserService {

    private final PasswordEncoder passwordEncoder;

    // 注册时加密密码
    public void register(UserDTO dto) {
        User user = new User();
        user.setUsername(dto.getUsername());
        // 加密密码
        user.setPassword(passwordEncoder.encode(dto.getPassword()));
        userMapper.insert(user);
    }

    // 登录时验证密码
    public boolean login(String username, String rawPassword) {
        User user = userMapper.selectByUsername(username);
        if (user == null) {
            return false;
        }
        // 验证密码
        return passwordEncoder.matches(rawPassword, user.getPassword());
    }
}
```

## 📋 设计原则

1. **最小化依赖**：
   - PageResult 不强制依赖 MyBatis-Plus
   - StringUtil 基于 Hutool，避免重复造轮子

2. **统一规范**：
   - 分页响应格式统一
   - 脱敏规则统一（手机号保留前3后4）

3. **安全第一**：
   - 密码加密使用 BCrypt 算法
   - 敏感信息自动脱敏
