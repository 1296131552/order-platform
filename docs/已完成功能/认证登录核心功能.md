## 功能概述

### 功能说明

认证登录模块是订单可视化平台的核心安全组件，提供完整的用户认证和授权功能。

**主要特性**：
- ✅ 支持用户名/邮箱/手机号三种登录方式
- ✅ 密码 BCrypt 加密存储
- ✅ JWT Token 认证
- ✅ 密码错误锁定机制
- ✅ 密码过期策略
- ✅ 角色权限管理
- ✅ 数据权限控制

**设计原则**：
- 安全第一：密码加密、Token验证、账户锁定
- 性能优化：批量查询、避免 N+1 问题
- 可扩展性：支持多种登录方式、配置化管理

## 核心功能

### 1. 用户登录

**功能描述**：用户通过账号和密码登录系统，支持用户名、邮箱、手机号三种方式。

**核心流程**：
```
1. 参数校验（账号、密码非空）
       ↓
2. 查询用户（支持用户名/邮箱/手机号）
       ↓
3. 验证用户状态（启用、锁定）
       ↓
4. 验证密码（BCrypt 匹配）
       ↓
5. 检查密码过期
       ↓
6. 查询用户角色和权限
       ↓
7. 查询数据权限范围
       ↓
8. 生成 JWT Token（包含角色信息）
       ↓
9. 更新登录信息（最后登录时间、登录次数）
       ↓
10. 清除密码错误计数器
       ↓
11. 记录操作日志
       ↓
12. 返回登录响应（Token + 用户信息）
```

**代码位置**：`AuthServiceImpl.login()` (order-platform-user/service/impl/AuthServiceImpl.java:81)

---

### 2. 用户登出

**功能描述**：用户退出登录，清除服务端状态。

**实现说明**：
- 验证 Token 有效性
- 记录登出操作日志
- Token 是无状态的，由客户端负责删除本地存储
- 未来可扩展 Redis 黑名单机制（TODO）

**代码位置**：`AuthServiceImpl.logout()` (order-platform-user/service/impl/AuthServiceImpl.java:128)

---

### 3. Token 刷新

**功能描述**：使用旧 Token 换取新 Token，延长用户登录时间。

**核心逻辑**：
```java
1. 验证旧 Token 并获取用户信息
2. 查询用户（验证用户是否存在）
3. 查询用户角色（获取最新角色信息）
4. 生成新 Token（包含最新角色信息）
5. 返回新 Token
```

**代码位置**：`AuthServiceImpl.refreshToken()` (order-platform-user/service/impl/AuthServiceImpl.java:155)

---

### 4. 修改密码

**功能描述**：用户修改自己的密码，需要验证旧密码。

**安全机制**：
- 验证旧密码（防止他人修改）
- 验证新密码强度
- 验证两次输入的新密码是否一致
- 检查新旧密码是否相同
- 更新密码过期时间

**代码位置**：`AuthServiceImpl.changePassword()` (order-platform-user/service/impl/AuthServiceImpl.java:190)

---

### 5. 重置密码

**功能描述**：管理员重置用户密码，生成随机密码。

**实现逻辑**：
- 生成 10 位随机密码（包含大小写字母、数字、特殊字符）
- BCrypt 加密后存储
- 更新密码过期时间
- 返回新密码（仅返回一次）

**代码位置**：`AuthServiceImpl.resetPassword()` (order-platform-user/service/impl/AuthServiceImpl.java:250)

---

### 6. 权限查询

**功能描述**：根据角色列表查询用户权限，支持多角色权限合并。

**核心特性**：
- 多角色权限叠加（并集）
- 权限去重
- 支持通配符（`*`、`MODULE:*`）
- 批量查询避免 N+1 问题

**代码位置**：`PermissionServiceImpl.getPermissionsByRoleIds()` (order-platform-user/service/impl/PermissionServiceImpl.java:59)

```
       ↓
4. 获取角色（混合方案：Token 优先，数据库兜底）
       ↓
5. 存入 ThreadLocal（CurrentUserHolder）
       ↓
6. 请求处理 → 业务代码通过 CurrentUserHolder 获取用户
       ↓
7. 请求结束 → afterCompletion 清理 ThreadLocal
```

## 安全机制

### 1. 密码安全

**BCrypt 加密**：
- 算法：Blowfish 加密算法的变体
- 强度：strength=10（2^10 次哈希迭代）
- 自动加盐：每次加密结果不同
- 单向加密：无法解密，只能验证匹配

**示例**：
```java
// 加密密码
String rawPassword = "123456";
String encodedPassword = passwordEncoderUtil.encode(rawPassword);
// 结果：$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy

// 验证密码
boolean matches = passwordEncoderUtil.matches(rawPassword, encodedPassword);
// 结果：true
```

---

### 2. 密码强度验证

**强度要求**（至少满足 3 项）：
1. 长度：6-20 字符
2. 包含大写字母
3. 包含小写字母
4. 包含数字
5. 包含特殊字符

**示例**：
```java
PasswordStrength strength = PasswordEncoderUtil.validateStrength("Abc123!@#");
// 结果：score=5, valid=true, message="密码强度符合要求"
```

---

### 3. 密码错误锁定

**锁定策略**（可配置）：
- 最大尝试次数：5 次
- 锁定时长：30 分钟

**实现位置**：`AuthServiceImpl.handlePasswordError()` (order-platform-user/service/impl/AuthServiceImpl.java:522)

**状态**：🚧 待实现（需要 Redis 支持密码错误计数器）

---

### 4. 密码过期策略

**过期时间**：90 天（可配置）

**验证逻辑**：
```java
if (user.getPasswordExpireTime() != null &&
    user.getPasswordExpireTime().isBefore(LocalDateTime.now())) {
    throw new BusinessException(ResponseCode.PASSWORD_EXPIRED, "密码已过期，请修改密码");
}
```

**代码位置**：`AuthServiceImpl.validatePasswordExpiration()` (order-platform-user/service/impl/AuthServiceImpl.java:512)

---

### 5. JWT Token 安全

**Token 特性**：
- 签名算法：HMAC-SHA256
- 过期时间：7 天（可配置）
- 包含用户信息：userId、username、roles

**Token 验证流程**：
```java
1. 检查 Token 格式（Bearer 前缀）
2. 验证签名（防止篡改）
3. 验证过期时间（防止重放）
4. 提取用户信息
```

**代码位置**：`AuthInterceptor.validateAndParseToken()` (order-platform-common/interceptor/AuthInterceptor.java:296)

---

### 6. 账户状态验证

**验证项**：
- `is_enabled`：账户是否启用（0=禁用，1=启用）
- `is_locked`：账户是否锁定（0=正常，1=锁定）
- `locked_time`：锁定过期时间（过期后自动解锁）

**代码位置**：`AuthServiceImpl.validateUserStatus()` (order-platform-user/service/impl/AuthServiceImpl.java:484)

## 配置说明

### 配置类：OrderPlatformProperties

**位置**：`order-platform-common/config/OrderPlatformProperties.java`

**配置结构**：
```yaml
order:
  platform:
    # 安全配置
    security:
      password:
        max-attempts: 5          # 密码错误最大尝试次数
        lock-minutes: 30         # 账户锁定时长（分钟）
        expire-days: 90          # 密码过期天数
        min-length: 6            # 密码最小长度
        max-length: 20           # 密码最大长度
        min-strength: 3          # 密码最小强度得分
      token:
        expiration: 604800       # Token过期时间（秒）

    # JWT配置
    jwt:
      secret: ${JWT_SECRET}      # JWT密钥（生产环境必须通过环境变量设置）
      expiration: 604800         # Token过期时间（秒）
      refresh-expiration: 1209600  # 刷新Token过期时间（秒）

    # 缓存配置
    cache:
      permission-ttl: 300        # 权限缓存TTL（秒）
      role-ttl: 300              # 角色缓存TTL（秒）
      enabled: true              # 是否启用缓存
```

## 使用示例

### 1. 用户登录示例

**Java 代码**：
```java
@Autowired
private AuthService authService;

// 构建登录请求
LoginDTO loginDTO = new LoginDTO();
loginDTO.setAccount("zhangsan");
loginDTO.setPassword("123456");

// 调用登录接口
LoginVO loginVO = authService.login(loginDTO);

// 获取 Token
String token = loginVO.getToken();

// 后续请求携带 Token
// Authorization: Bearer {token}
```

**cURL 示例**：
```bash
curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "account": "zhangsan",
    "password": "123456"
  }'
```

```java
// 从登录响应中获取 Token
String token = loginVO.getToken();
```

## 注意事项

### 1. 安全建议

- ✅ **生产环境必须修改 JWT 密钥**：通过环境变量 `JWT_SECRET` 设置
- ✅ **使用 HTTPS**：防止 Token 被窃取
- ✅ **定期更换密码**：建议用户每 90 天更换一次密码
- ✅ **强密码策略**：启用密码强度验证
- ⚠️ **不要在日志中打印密码**：即使是加密后的密码
