# 操作日志功能

> **功能说明**：记录用户对业务实体的操作，用于审计追溯
>
> **完成日期**：2026-01-07
> **维护人**：开发组

---

## 📋 功能概述

操作日志功能用于记录系统中所有重要操作的审计信息，支持：

- **多态关联**：支持订单、订单行、发运、快递单、供应商、承运商、客户、异常、附件等多种业务实体
- **混合存储**：核心信息存 MySQL，详细快照存对象存储（暂时存入 extra_info 字段）
- **异步保存**：独立线程池异步执行，不影响业务性能
- **SpEL 支持**：支持使用 Spring 表达式语言动态获取业务关联信息

## 📦 实现内容

### 1. 枚举类

#### BusinessType（业务类型）

支持的业务类型：
- `ORDER`：订单
- `ORDER_LINE`：订单行
- `SHIPMENT`：发运批次
- `SHIPMENT_LINE`：快递单
- `RECEIPT`：签收明细
- `CUSTOMER`：客户
- `SUPPLIER`：供应商
- `CARRIER`：承运商
- `EXCEPTION`：异常记录
- `ATTACHMENT`：附件
- `USER`：用户
- `ROLE`：角色

#### OperationType（操作类型）

支持的操作类型：
- `CREATE`：创建
- `UPDATE`：更新
- `DELETE`：删除
- `VIEW`：查看
- `EXPORT`：导出
- `IMPORT`：导入
- `AUDIT`：审核
- `CONFIRM`：确认
- `APPROVE`：审批
- `CANCEL`：取消
- `LOGIN`：登录
- `LOGOUT`：登出

#### OperationModule（操作模块）

支持的模块：
- `ORDER`：订单管理
- `PARTNER`：合作方管理
- `SHIPMENT`：发运管理
- `RECEIPT`：签收管理
- `ATTACHMENT`：附件管理
- `EXCEPTION`：异常管理
- `VISUALIZATION`：可视化
- `DASHBOARD`：看板
- `SYSTEM`：系统管理
- `USER`：用户管理

### 2. 注解使用

#### 注解定义

```java
@OperationLog(
    business = BusinessType.ORDER,           // 业务类型
    type = OperationType.CREATE,              // 操作类型
    module = OperationModule.ORDER,           // 操作模块
    description = "创建订单",                  // 操作描述
    saveSnapshot = false,                     // 是否保存快照
    businessId = "#result.id",                // 业务ID表达式
    businessNo = "#result.orderNo",           // 业务编号表达式
    businessName = "#result.customerName"     // 业务名称表达式
)
```

#### 使用示例

**Controller 层**：

```java
@PostMapping("/order/create")
@OperationLog(
    business = BusinessType.ORDER,
    type = OperationType.CREATE,
    module = OperationModule.ORDER,
    description = "创建订单",
    businessId = "#result.id",
    businessNo = "#result.orderNo"
)
public Result<Order> createOrder(@RequestBody OrderDTO dto) {
    Order order = orderService.create(dto);
    return Result.ok(order);
}
```

**Service 层**：

```java
@Service
public class OrderService {

    @OperationLog(
        business = BusinessType.ORDER,
        type = OperationType.UPDATE_STATUS,
        description = "更新订单状态",
        businessId = "#orderId"
    )
    public void updateStatus(Long orderId, String newStatus) {
        // 业务逻辑
    }
}
```

## 📋 数据库表设计

### 表结构

**表名**：`t_operation_log`

**存储引擎**：InnoDB

**字符集**：utf8mb4_unicode_ci

**核心字段**：

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | BIGINT | 是 | AUTO_INCREMENT | 主键ID |
| operator_id | BIGINT | 是 | -1 | 操作人ID（-1表示系统） |
| operator_name | VARCHAR(50) | 是 | '' | 操作人姓名（冗余） |
| business_type | VARCHAR(50) | 是 | - | 业务类型（多态关联） |
| business_id | BIGINT | 是 | - | 业务ID（多态关联） |
| business_no | VARCHAR(100) | 是 | '' | 业务编号（冗余） |
| operation_type | VARCHAR(30) | 是 | - | 操作类型 |
| operation_module | VARCHAR(50) | 是 | '' | 操作模块 |
| operation_desc | VARCHAR(500) | 是 | '' | 操作描述 |
| operation_result | VARCHAR(30) | 是 | 'SUCCESS' | 操作结果 |
| result_desc | VARCHAR(500) | 是 | '' | 操作结果描述 |
| operation_ip | VARCHAR(50) | 是 | '' | 操作IP |
| request_path | VARCHAR(500) | 是 | '' | 请求路径 |
| request_method | VARCHAR(10) | 是 | '' | 请求方法 |
| operation_time | DATETIME(3) | 是 | CURRENT_TIMESTAMP(3) | 操作时间 |
| operation_duration | INT | 否 | NULL | 操作耗时（毫秒） |
| snapshot_key | VARCHAR(500) | 否 | NULL | 快照文件Key |
| extra_info | JSON | 否 | NULL | 扩展信息 |
| is_deleted | TINYINT | 是 | 0 | 是否删除 |

### 索引设计

| 索引名 | 字段 | 说明 |
|--------|------|------|
| idx_operation_log_operator_time | operator_id, operation_time, is_deleted | 用户操作历史查询 |
| idx_operation_log_business_time | business_type, business_id, operation_time, is_deleted | 业务实体操作历史 |
| idx_operation_log_type_module | operation_type, operation_module, operation_time, is_deleted | 操作类型模块统计 |
| idx_operation_log_time_result | operation_time, operation_result, is_deleted | 操作时间结果统计 |

### 查询示例

```sql
-- 1. 查询某用户的操作历史
SELECT * FROM t_operation_log
WHERE operator_id = ? AND is_deleted = 0
ORDER BY operation_time DESC;

-- 2. 查询某订单的操作历史
SELECT * FROM t_operation_log
WHERE business_type = 'order' AND business_id = ? AND is_deleted = 0
ORDER BY operation_time DESC;

-- 3. 统计某时间段内各操作类型的数量
SELECT operation_type, COUNT(*) as count
FROM t_operation_log
WHERE operation_time >= ? AND operation_time < ? AND is_deleted = 0
GROUP BY operation_type;

-- 4. 查询某模块的失败操作
SELECT * FROM t_operation_log
WHERE operation_module = 'ORDER' AND operation_result = 'FAILED' AND is_deleted = 0
ORDER BY operation_time DESC;

-- 5. 统计操作成功率
SELECT operation_result, COUNT(*) as count
FROM t_operation_log
WHERE operation_time >= ? AND operation_time < ? AND is_deleted = 0
GROUP BY operation_result;
```

## 📝 使用示例

### 查询用户操作历史

```java
// 查询某用户的操作历史
LambdaQueryWrapper<OperationLog> wrapper = new LambdaQueryWrapper<>();
wrapper.eq(OperationLog::getOperatorId, userId)
       .eq(OperationLog::getIsDeleted, 0)
       .orderByDesc(OperationLog::getOperationTime);

List<OperationLog> logs = operationLogMapper.selectList(wrapper);
```

### 查询业务实体操作历史

```java
// 查询订单的操作历史
LambdaQueryWrapper<OperationLog> wrapper = new LambdaQueryWrapper<>();

       .eq(OperationLog::getBusinessId, orderId)
       .eq(OperationLog::getIsDeleted, 0)
       .orderByDesc(OperationLog::getOperationTime);
```
