## 📋 功能概述

### 功能说明

集成 Spring Boot DevTools，实现代码修改后的自动重启，提高开发效率。

### 特性

- ✅ 自动重启：Java 代码修改后自动重启应用
- ✅ 快速重启：只重启变化的类，而非整个应用
- ✅ 配置灵活：可排除不触发热重载的资源
- ✅ 性能优化：通常 1-3 秒即可完成重启

---

## 🔧 实现细节

### 1. 添加 Maven 依赖

**文件**：`order-platform-api/pom.xml`

```xml
<!-- ==================== 开发工具 ==================== -->
<!-- DevTools：热重载，提高开发效率 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

### 2. 配置 application.yml

**文件**：`order-platform-api/src/main/resources/application.yml`

```yaml
# ==================== DevTools 热重载配置 ====================
spring:
  devtools:
    # 启用热重载
    enabled: true
    # 排除不触发热重载的资源
    exclude: static/**,public/**,templates/**
    # 监控额外资源
    additional-paths: src/main/java
    # 禁用 LiveReload（可选，如需浏览器自动刷新则设为 true）
    livereload:
      enabled: false
    # 重启策略
    restart:
      # 启用重启
      enabled: true
      # 排除不触发重启的资源（提高性能）
      exclude: static/**,public/**,templates/**,META-INF/maven/**,META-INF/resources/**
```

## 📖 使用方法

### 启动项目（支持热重载）

```bash
cd order-platform-api
mvn spring-boot:run
```

### 触发热重载

1. 修改 Java 代码
2. **编译**（IDEA：`Build → Build Project` 或快捷键 `Ctrl+F9`）
3. **自动重启**（DevTools 会自动检测变化并重启应用）

### 能热重载的场景 ✅

| 场景 | 说明 |
|------|------|
| 修改**已有** Java 类的方法内容 | 重启 ClassLoader（快，1-3秒）|
| 修改 Controller、Service | 立即生效 |
| 修改静态资源 | 浏览器刷新 |

### 不能热重载的场景 ❌

| 场景 | 说明 |
|------|------|
| **新增** Java 文件 | 不在监控列表中 |
| **新增** @Configuration 类 | 需要重新扫描 |
| **新增** 依赖 | 需要重新下载 jar |
| 修改 pom.xml | Maven 依赖树变化 |
| 修改 application.yml 某些配置 | Spring 上下文已初始化 |

## ⚙️ 工作原理

### 双类加载器机制

```
┌─────────────────────────────────────────────┐
│   Base ClassLoader                           │
│   (第三方依赖 jar，不变)                      │
├─────────────────────────────────────────────┤
│   Restart ClassLoader                        │
│   (应用代码，可重新加载)                      │
└─────────────────────────────────────────────┘
```

### 验证方法

**热重载的日志**：
```
2026-01-08 15:23:45.234 --- [  restartedMain] ...
```
注意：`restartedMain` → 表示热重载

**完全重启的日志**：
```
2026-01-08 15:25:10.123 --- [           main] ...
```
注意：`main` → 表示完全重启
