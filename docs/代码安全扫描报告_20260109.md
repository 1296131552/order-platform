### 问题 1：SpEL 表达式注入风险

**位置**：`order-platform-common/src/main/java/com/order/platform/common/aspect/OperationLogAspect.java:380`

**风险等级**：⚠️ WARNING（低置信度）

**漏洞类型**：CWE-94 代码注入

**OWASP 分类**：A03:2021 - Injection

**检测规则**：`java.spring.security.audit.spel-injection.spel-injection`

**问题描述**：
```java
// 第 380 行
Expression expression = parser.parseExpression(expressionString); // nosemgrep: java.spring.security.audit.spel-injection.spel-injection
Object value = expression.getValue(context, variables);
```

**实际风险评估**：✅ **安全可控**

**原因分析**：
1. ✅ **已使用 SimpleEvaluationContext**：限制了 SpEL 的功能，禁用了方法调用和类引用
2. ✅ **已实现白名单验证**：在第 377 行调用了 `validateExpression()` 进行输入验证
3. ✅ **已添加 nosemgrep 注释**：开发者已知晓此警告并评估为安全
4. ✅ **异常处理完善**：捕获了 SecurityException 和 Exception

**防护措施**：
```java
// 1. 白名单验证（第 377 行）
validateExpression(expressionString);

// 2. 使用安全的上下文（SimpleEvaluationContext 而非 StandardEvaluationContext）

// 3. 异常处理（第 384-390 行）
catch (SecurityException e) {
    log.warn("SpEL 表达式安全验证失败: {}, error={}", expressionString, e.getMessage());
    return null;
}
```

**建议**：
- ✅ **保持现状**：当前实现已经足够安全

    try {

## 🎓 学习要点

### 1. SpEL 安全最佳实践

`★ Insight ─────────────────────────────────────`
**Spring Expression Language (SpEL) 安全三原则**：

1. **使用 SimpleEvaluationContext**：
   - 禁用方法调用
   - 禁用类引用
   - 限制基本属性访问

2. **输入验证**：
   - 白名单验证允许的表达式格式
   - 拒绝包含特殊字符的输入

3. **异常处理**：
   - 捕获所有异常避免信息泄露
   - 记录安全事件用于审计
`─────────────────────────────────────────────────`

### 2. 密码哈希安全

`★ Insight ─────────────────────────────────────`
**BCrypt 哈希特性**：
- 每次加密结果都不同（盐值随机）
- 输出固定长度 60 字符
- 格式：`$2a$10$...`（算法+成本因子+盐值+哈希）

**安全要点**：
- ✅ 注释中的示例哈希不构成安全风险
- ✅ 明确标注"仅供演示"可以避免误解
- ❌ 永远不要在代码中硬编码真实凭据
`─────────────────────────────────────────────────`
